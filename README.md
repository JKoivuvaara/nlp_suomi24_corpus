## Installation

Requires Python 3.10+

Run:
    pip install -r requirements.txt

## Download Suomi24 archive or intermediery results

1. Download the Suomi24 2001-2017 v1.3 zip file from:

    https://www.kielipankki.fi/download/Suomi24/2001-2017/

2. Do not extract the archive, the program reads it in zipped format!

3. Save the zip file in this directory (or somwehere else, but you may have to change a couple lines of code).

4. Alternatively if you dont want to do the above steps, as running the queries and scans can take a long time, you can download the intermediary 
results from [ ], unzip them, and place the folders inside this directory.
